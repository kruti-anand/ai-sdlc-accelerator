# AI SDLC Accelerator

A portfolio prototype for an AI-assisted Software Development Lifecycle workflow.

## BRD prototype

Open `index.html` in a browser, or serve the repository with any static web server. The prototype demonstrates the first human-in-the-loop workflow:

1. Enter a business requirement (or load the MFA example).
2. Run a client-side AI-style analysis that separates known information from gaps.
3. Answer structured clarification questions.
4. Generate and review a traceable BRD draft.

This version intentionally uses deterministic browser logic rather than an external model or enterprise data. Assumptions are labelled in the generated document so the experience can later be connected to a model API without changing the workflow.
